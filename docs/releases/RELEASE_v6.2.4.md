# PVM Standard 6.2.4

6.2.4は、入力データの取り扱いと初回エラーを安全にする修正リリースです。クラスタリング、候補選定、baseline、lock / unlockの計算とschema 2.1は変更していません。

## 変更

- 欠損・空本文を埋め込み前に除外し、除外件数を警告します。
- `id` / `ID` 列を自動検出して元データのIDを保持します。
- 初回候補探索に必要な件数を埋め込み前に検証し、`k_min` に対応したメッセージを表示します。
- Ruri v3に必要な `transformers>=4.48` を依存条件へ反映しました。
- `AI_解釈依頼.md` に原文代表例を含むことと、外部AIへ渡す際の注意を表示します。

baseline schemaは **2.1** のままです。既存の6.2.x baselineを継続利用できます。
