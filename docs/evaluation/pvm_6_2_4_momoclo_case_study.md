# PVM Standard 6.2.4 実テキスト動作検証

[トップ](../../README.md) · [評価手順](../evaluation_protocol.md) · [再実行スクリプト](../../benchmark/README.md) · [資料一覧](../README.md)

## この検証で知りたいこと

この検証の目的は、PVMが世界最高性能であることを証明することではありません。ラベルのない日本語ウェブテキストを実際に整理したとき、次の最低限を満たすかを確認します。

- 素のクラスタリングより、PVMの整理工程を通す意味があるか
- Centroid Projectionは文章の所属をどのように整理するか
- 一度作ったクラスタをlockして、別の文章にも概ね再利用できるか

## 結論

ももクロ関連テキスト5,000件では、PVMは実用を検討できる動きをしました。

- PCA＋ICA①による低次元整理を加えると、素のクラスタリングより乱数seedに対して安定しました。
- 実データの安定性は、文章構造を壊したshuffled対照より明確に高くなりました。
- Centroid Projectionは全体を作り直さず、クラスタの中心を保ちながら少数の境界文を調整しました。
- holdoutへのlockは多くの分割で全件クラスタリングと近い結果になりました。ただし一部の分割では崩れました。
- PVM完全版（PCA → ICA① → Centroid Projection → クラスタリング）の代表文が、素のクラスタリングより常に読みやすいとまでは確認できませんでした。

したがって、この結果が示すのは「PVMはこの実テキストで破綻せず、素の方法と比べて安定性と再利用性に一定のメリットがあった」という範囲です。他のデータでも必ず優位になる、正解クラスタを発見できる、という主張ではありません。

## 比較した処理

embedding、クラスタ数、乱数seedを揃え、処理の段だけを変えました。

| 比較名 | 処理 |
|---|---|
| 素のクラスタリング | embedding → spherical k-means |
| PCAのみ | PCA → spherical k-means |
| PCA＋ICA① | PCA → ICA① → spherical k-means |
| PVM完全版 | PCA → ICA① → Centroid Projection → spherical k-means |

採用された設定はICA① 6次元、4クラスタ、Centroid Projection 3次元です。PCAのみは分散90%を保持した228次元、PCA＋ICA①は6次元なので、両者の差をICA①単体の効果とは扱いません。ここでは「PCA＋ICA①による低次元整理」の効果として評価します。

## 実際の結果

### 1. 同じ処理を繰り返しても大きく崩れないか

5種類のseedでクラスタリングし、結果同士の一致度をARIで測りました。1に近いほど同じ整理が再現されています。

| 処理 | 実データ | shuffled対照 |
|---|---:|---:|
| 素のクラスタリング | 0.626 | 0.185 |
| PCAのみ | 0.588 | 0.007 |
| PCA＋ICA① | 0.970 | 0.238 |
| PVM完全版（PCA → ICA① → Centroid Projection → クラスタリング） | 0.971 | 0.195 |

PCA＋ICA①まで整理した結果とPVM完全版は、素のクラスタリングより安定しました。また、すべての処理で実データがshuffled対照を上回りました。

分散90%を保持した228次元のPCAのみでは、素のクラスタリングより安定性は上がりませんでした。6次元化自体の効果は、この検証では切り分けていません。

共通評価空間でのsilhouetteは実データの各処理で0.0472〜0.0485とほぼ同じでした。分離指標の大幅な改善を根拠にPVMの優位を主張する結果ではありません。

### 2. Centroid Projectionは何を変えたか

Centroid Projectionを加えたとき、所属が変わった文章はseed平均で全体の0.604%でした。採用planのseed 42では38件、0.76%です。

移動したのはクラスタ境界に近い文章に集中し、各クラスタの中心的な文章は維持されました。本文を読むと、ももクロ中心の記事が公演・公式情報側へ寄る、個人の参加記録がブログ側へ寄る、と理解できる例がありました。一方、短い抜粋だけでは移動先の妥当性を断定できない例もあります。

このデータでのCentroid Projectionは、新しい話題を発見する処理というより、ICA①で整理した空間からクラスタ間の違いを残し、少数の境界文を調整する処理として働きました。

### 3. 作ったクラスタをholdoutへ再利用できるか

70%の文章で変換とクラスタを作り、残り30%へlock適用しました。これを10通りの分割で繰り返しています。

| データ | 平均ARI | 中央値 | 最小 | 最大 |
|---|---:|---:|---:|---:|
| 実データ | 0.809 | 0.908 | 0.497 | 0.944 |
| shuffled対照 | 0.056 | 0.054 | 0.037 | 0.102 |

実データでは10回中7回が0.86以上でした。一方で0.5未満も1回あり、標本の分け方に関係なく安定するわけではありません。lockは再利用を試す根拠になりますが、結果確認や定期的なbaseline reviewは必要です。

比較先の全件クラスタリングも正解ラベルではありません。このARIは「全件で作り直した場合との整合」を見ており、意味的な正解率ではありません。

### 4. 実際の文章を読んだ結果

代表文と所属変更文は、結果を見て都合よく選ばず、centroid距離、ICA①軸の両端、クラスタ境界までの距離という固定規則で抽出しました。

素のクラスタリングとPVM完全版の双方で、概ね次のまとまりを読めました。

- 広い音楽・アイドル関連記事
- 個人ブログ・生活記録
- ももクロの公演・公式情報
- 一般芸能・人物紹介・まとめ記事

ICA①の6軸には、元メンバーと音楽イベント、長文記事と定型まとめ、個人の日記と芸能ニュース、具体的なももクロイベントと広いアイドル比較など、複数の読める対比がありました。ただし純粋な話題だけでなく、媒体や文体の違いも含まれます。

PVM完全版の代表文が素のクラスタリングより明確に読みやすい、という差は確認できませんでした。Centroid Projectionの価値は、クラスタ全体の劇的な改善ではなく、中心を維持した境界整理として観測されました。

固定規則で抽出した短い本文は [本文確認用データ](./artifacts/pvm_6_2_4_momoclo_qualitative_examples.md)、抽出役割と本文ハッシュは [manifest](./artifacts/pvm_6_2_4_momoclo_qualitative_manifest.csv) で確認できます。

## この結果から言える範囲

- **低次元整理**: このデータでは、PCA＋ICA①を通した方が素のクラスタリングより再現しやすい整理になりました。
- **Centroid Projection**: コアを壊さず、少数の境界文を調整しました。大幅な性能向上や可読性向上は確認していません。
- **lock**: 多くの分割で再利用できましたが、分割によって崩れるため無監視運用の保証ではありません。
- **全体**: 「実データで使え、素の方法より一定のメリットがある」という下限を確認しました。
