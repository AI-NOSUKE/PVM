# PVM Standard 6.2.4 ももクロ実テキスト・ケーススタディ

[トップ](../../README.md) · [評価手順](../evaluation_protocol.md) · [再実行スクリプト](../../benchmark/README.md) · [資料一覧](../README.md)

## 結論

この5,000件では、効果の中心はICA①でした。V3（PCA + ICA①）はV1/V2よりseed安定性が高く、実データと列シャッフル対照の差も大きく出ました。一方、V4のCentroid Projection（CP）はV3を全面的に作り替えず、実データでは平均0.604%の境界文だけを動かしました。V4の代表文がV1より明確に読みやすい、とまでは判定できません。

holdout lockはrealで平均ARI 0.809・中央値0.908、shuffledで平均0.056でした。ただしrealにも0.497まで下がる分割が1回あり、分割に関係なく堅牢とは言えません。したがって、この結果が支えるのは「PVMの段構成はこのコーパスで非自明に働き、lock運用を試す根拠はある」という下限です。汎用的優位性や正解クラスタの発見を証明する結果ではありません。

## 問いと比較条件

ラベル無しのももクロ関連日本語ウェブテキストについて、次を確認しました。

1. PCA → ICA① → CPと段を重ねることに、素のspherical k-meansを超える観測可能な効果があるか。
2. 効果が列間相関を壊したshuffled対照でも同様に現れないか。
3. trainで作ったplanとcentroidをholdoutへlock適用した割当が、全件同時クラスタリングと整合するか。
4. 代表文、ICA①の両端、CPで所属が変わった文を人が読んだとき、数値の説明と中身が一致するか。

| variant | 変換 |
|---|---|
| V1 | embedding → spherical k-means |
| V2 | embedding → PCA → spherical k-means |
| V3 | embedding → PCA → ICA① → spherical k-means |
| V4 | V3 → Centroid Projection → spherical k-means |

embedding、`k=4`、ICA①次元 `d=6`、seed集合は全variantで共通です。`k` と `d` はPVM 6.2.4の `standard` 探索でrealから一度だけ選び、その後は比較条件として固定しました。分離指標はvariant固有の変換後空間ではなく、共通のPCA L2評価空間で測っています。

- embedding: `cl-nagoya/ruri-v3-310m`、prefix `トピック: `、`max_len=384`
- embedding形状: 5,000 × 768、SHA-256 `4caa9ed26e26d2d88204dd658c47d15128367d63dbaa47918559c62fa0614c8e`
- PVM: `PVM-standard-6.2.4`、commit `22659c2927eb6c03af175e7e1561bcf108d0204f`
- 実行環境: Python 3.14.6、torch 2.13.0+cpu、scikit-learn 1.9.0、NumPy 2.5.1、pandas 2.3.3、CPU

## 採用plan

| 項目 | 値 |
|---|---:|
| ICA①次元 | 6 |
| cluster数 | 4 |
| CP rank | 3 |
| selection tier | `strict_full` |
| usable ICA① axes | 6 |
| 探索内seed安定性 | 0.961 |
| CP変更数（seed 42） | 38 / 5,000（0.76%） |
| boundary focus | 1.000 |
| core preservation | 1.000 |

旧来問題だった `d=2` 固定ではなく、6軸を保持したうえでCPが3次元へ実際に削減するplanが選ばれました。`usable=6` は機械的診断を通った軸数であり、6軸すべてが人間に同程度に明瞭な話題軸だという意味ではありません。

## A. アブレーションとshuffled対照

`stability ARI` は5 seed全10ペアの平均です。`silhouette` は全variant共通のPCA L2空間での平均です。

| variant | stability real | stability shuffled | silhouette real | silhouette shuffled |
|---|---:|---:|---:|---:|
| V1 | 0.626 | 0.185 | 0.0479 | 0.0016 |
| V2 | 0.588 | 0.007 | 0.0472 | 0.0027 |
| V3 | 0.970 | 0.238 | 0.0485 | 0.0026 |
| V4 | 0.971 | 0.195 | 0.0485 | 0.0025 |

観測できる主効果はV2→V3のseed安定性上昇です。V4はV3とほぼ同じで、CPによる追加の安定性向上は示されません。realのsilhouetteも全variantでほぼ同じなので、分離指標だけからV4の優位は主張できません。

すべてのvariantでrealの安定性がshuffledを上回り、silhouetteもrealの方が一桁以上大きくなりました。少なくとも、実データの結果が各embedding次元の周辺分布だけから同程度に生じたわけではない、と解釈できます。

CPのV3からの所属変更率はrealでseed平均0.604%でした。shuffledでは平均18.416%で、seedごとに0.94%〜40.90%と不規則でした。realで `boundary_focus=1.0`、`core_preservation=1.0` だったことと合わせると、CPは実データではコアを壊さず境界を微調整し、相関構造を壊した対照では安定した整理規則になっていない、という動きです。

## B. holdout lock

10通りの固定split seedで70%をtrain、30%をholdoutとしました。trainだけで変換とcentroidを学習し、holdoutへlock適用したラベルを、全5,000件で同時クラスタリングしたholdout部分とARI比較しました。

| data | 平均 | 中央値 | 最小 | 最大 | ARI < 0.5 |
|---|---:|---:|---:|---:|---:|
| real | 0.809 | 0.908 | 0.497 | 0.944 | 1 / 10 |
| shuffled | 0.056 | 0.054 | 0.037 | 0.102 | 10 / 10 |

realの10回中7回は0.86以上で、shuffledとの差は大きく出ました。ただしrealの3回は0.637以下で、そのうち1回は0.5未満です。lockはこのデータで有望ですが、標本の取り方への感度が残るため、未知データで無監視に固定できるという結論にはしません。

なお、比較先の全件クラスタリングも正解ラベルではありません。このARIは「同じPVMを全件へ再学習した場合との整合」であり、外部妥当性や意味的正解率ではありません。

## C. 本文を読んだ評価

本文は結果を見て都合よく選ばず、次の固定規則で抽出しました。

- V1/V4: 各clusterでcentroid距離が近い2文
- ICA①: 各軸の正側・負側それぞれ上位2文
- CP: 各V3→V4遷移でV3割当marginが小さい順に最大2文

全抜粋は [qualitative examples](./artifacts/pvm_6_2_4_momoclo_qualitative_examples.md)、選択役割とハッシュは [manifest](./artifacts/pvm_6_2_4_momoclo_qualitative_manifest.csv) にあります。

### クラスタ

V1とV4の双方で、概ね「広い音楽・アイドル関連記事」「個人ブログ・生活記録」「ももクロの公演・公式情報」「一般芸能・人物紹介／まとめ記事」に相当するまとまりを読めました。ただし、V4の中心例にもAKBの掲示板文や一般芸能見出し集が含まれます。今回の固定抽出だけから、V4がV1より一貫して読みやすいとは評価しません。

### ICA①

6軸の両端には、次のような対比が見えました。

| 軸 | 読み取れた主な対比 | 留保 |
|---|---|---|
| 1 | 元メンバーの卒業・人物紹介 ↔ 音楽特番・フェス | 比較的明瞭 |
| 2 | 長文の音楽記事・取材 ↔ 買い物まとめの定型文 | 話題と媒体文体の混合 |
| 3 | 一般エンタメ記事 ↔ ファン／掲示板的語り | 正側のまとまりは弱い |
| 4 | 衰退論・論争 ↔ 公式企画・人物紹介 | 一部に一般社会記事が混ざる |
| 5 | 個人の日記・回想 ↔ 芸能ニュース／見出し集 | 比較的明瞭 |
| 6 | 具体的なももクロイベント・接点 ↔ 広いアイドル／K-POP比較 | 比較的明瞭 |

したがってICA①は複数の読める整理軸を返していますが、純粋な「話題」だけでなく、媒体、文体、ノイズ量も分離しています。全6軸を同じ品質の意味軸とは扱いません。

### Centroid Projection

移動文には、ももクロ中心の記事が公式・公演側へ寄る、現地参加や個人記録がブログ側へ寄る、と読める例があります。一方、防音室の体験談、ニュース寄せ集め、野球記事など、移動先の妥当性を短い抜粋だけで断定できない例もあります。

このためCPの役割は「ICA①から新しい話題を発見すること」ではなく、ICA①空間のうちcluster重心間を区別する方向を残し、境界文の所属を少数調整することだと評価します。このデータではコア保存と境界集中は確認できましたが、クラスタ全体の読みやすさ改善は未確認です。

## 総合判定

- **段を重ねる効果**: あり。ただし根拠の中心はICA①による安定性と読める複数軸で、CPの追加効果は小さな境界整理です。
- **構造が偶然でないか**: 列シャッフル対照との差は明確です。ただし一つの人工対照に対する結果です。
- **lock運用**: 試す妥当性はありますが、分割感度があり監視・定期reviewが必要です。
- **CPの価値**: コアを保った境界調整として残す根拠はあります。V3を超える数値的・可読性的優位を断定する証拠はありません。

## 限界

- 一つのドメイン、一つの日本語embedding、5,000件だけのケーススタディです。
- 正解ラベルがなく、本文評価は盲検の複数評価者によるものではありません。
- shuffled対照は列間相関を壊す人工対照で、別手法との外部ベンチマークではありません。
- `k` とICA①次元はrealで選択しており、完全に独立した検証データでのモデル選択ではありません。
- 原文を再配布していないため、第三者が同一結果を完全再現するには同一入力を別途保有する必要があります。

機械可読の集約値は [metrics.json](./artifacts/pvm_6_2_4_momoclo_metrics.json)、seed・split単位の値は [runs.csv](./artifacts/pvm_6_2_4_momoclo_runs.csv) を参照してください。
